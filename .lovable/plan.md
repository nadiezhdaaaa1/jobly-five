## Goal

Load the uploaded `jobly-fake-jobs-12000.json` (12,000 jobs) as the app's job catalog, replacing the current 6,324 rows in `public.jobs`.

## Steps

1. **Wipe and reseed `public.jobs`** in a single migration:
   - `TRUNCATE public.jobs;`
   - Bulk `INSERT` all 12,000 rows from the JSON, mapping fields to existing columns:
     - `id`, `title`, `group`, `roles`, `role_ids` (→ `roleIds`), `seniority`, `min_years_experience`, `work_mode` (→ `workMode`), `location`, `company`, `company_sector`, `company_domain`, `stack`, `hard_skills`, `tools`, `soft_skills`, `salary_min`, `salary_max`, `posted_days_ago`, `source`.
     - `english_level` is not in the uploaded data → leave `NULL` (match.ts already tolerates null; job cards render "B2+" default in description).
   - Schema is unchanged; no new columns, RLS, or grants needed.

2. **Raise the client fetch cap** in `src/lib/jobs-store.ts`:
   - `supabase.from("jobs").select("*").limit(5000)` → `.limit(12000)`.

3. **No UI changes.** The Digest wall already paginates 15/page, the Tracker widget and filters read from the same store, so results scale automatically.
